# VPN Manager - VPNM test suite

The `VPN Manager - VPNM` is responsible for managing anything related to `VPN`:

- Managing `VPN` tunnels agnostic of the implementation or type.
- `VPN` tunnel healthcheck and status reporting.
- Creating and managing `IPSec` tunnels.
- Creating and managing tunnel interfaces: `vti/vti6`, `ip6tnl`, `gre`, `gretap`, `ip6gre`, `ip6gretap`, etc.
