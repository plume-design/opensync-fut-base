# Onboarding - ONBRD test suite

The `Onboarding - ONBRD` test suite provides device verification for the process of onboarding to the `Cloud`.

The test suite does not use any connection to an actual `Cloud` deployment. The services are simulated on the testbed
server, which is sufficient to keep `CM` operational and prevent the device from resetting or restarting due to failed
cloud connectivity.
